# Cloudedee

An animated YouTube series made entirely in code with [Remotion](https://www.remotion.dev).
Characters, sets, sound effects and music are all generated by code; voices come from ElevenLabs.

## If you want to watch or render on your own computer (optional)

You don't need to do this. Claude renders the videos and sends you the MP4. It's here in case you want to.

1. Install **Node.js** (the "LTS" version) from https://nodejs.org. Use the normal installer.
2. Download this project from GitHub (green **Code** button → **Download ZIP**), then unzip it.
3. Open a terminal in the project folder:
   - On a Mac: right-click the folder → **New Terminal at Folder**.
   - On Windows: open the folder, click the address bar, type `cmd`, then press Enter.
4. Type `npm install` and press Enter. Wait for it to finish (this only has to happen once).
5. Type `npm run studio` and press Enter. A browser window opens and you can watch every episode and scroll through it.
6. To make an MP4, type `npm run render -- ep00`. The video is saved in the `out` folder.

# CLAUDE.md – Cloudedee series bible & production guide

This repo is an animated YouTube series built **entirely in code** with Remotion 4 (React).
The owner is not a developer: explain anything they must do in simple numbered steps.
Claude is writer, director, animator, editor and sound designer.

---

## 1. Series rules (never break these)

1. **Everything is drawn in code**: flat vector style, thin outlines (`#2b2333`), soft shadows, subtle gradients.
   No stock footage, no AI-generated video/images, no pre-made animations, no stock audio.
2. **Formats**: episodes 1920×1080 @ 30 fps; Shorts/Reels 1080×1920 @ 30 fps. Thin black letterbox bars (34 px / 22 px).
3. **Every spoken line is visible** – speech bubbles for characters, caption strip for the narrator (works with sound off).
4. **SFX + music are generated by `scripts/generate-audio.mjs`** (maths only). Add new sounds there, never download any.
5. **Voices = ElevenLabs connector only.** One narrator voice for the whole series (never change it). One distinct voice per character.
6. **Monetization safety (no "repetitive content")**: every episode gets NEW locations, new side characters,
   varied camera work and original jokes. Reuse the *library* (rig, props, effects), never a whole scene as a template.
   Recolour/recombine sets, change time of day, change camera language (push-ins, whip pans, low angles, wide two-shots, close-ups).
7. **Continuity** is tracked in section 5 below – update it after every episode.
8. **Commit to git after every milestone** (library change, voices imported, scene built, episode rendered).

## 3. Production steps (every episode)

1. **Script in** – the owner may send it in parts: merge everything into ONE episode.
2. **Write** `src/episodes/epXX/script.ts`: scenes as step lists (see §4). Every line starts with a delivery tag,
   e.g. `say('l014', 'mira', '[whispering, nervous] Is it gone?', {mood: 'worried'})`. Narrator: `narrate('n03', '[warm] ...')`.
   Line ids are unique within the episode (`n01…` narrator, `<initial>01…` per character works well).
3. `npm run lines -- epXX` → dialogue list + character count. Check credits with `account_get_usage`;
   **tell the owner the estimated cost** (eleven_v4 ≈ 1 credit per character incl. tags) before generating.
4. **Voices**: `creative_create_flow` once per episode (name "Cloudedee epXX"), then for each line
   `creative_generate_speech` with `model_id: eleven_v4`, `generations_count: 1`, the cast voice_id and that flow_id.
   **Never call generate again to "retry"** (it charges again). Poll `creative_get_flow_run_status` until done.
   Put each `content_url` into `episodes/epXX/downloads.json` as `{ "lineId": "url" }`.
5. `npm run voices:import -- epXX` → downloads with curl, converts to mono 44.1 kHz WAV
   (ffmpeg inside `node_modules/@remotion/compositor-*`), writes `public/voices/epXX/*.wav`
   and `src/generated/voices/epXX.json` (durations + per-frame loudness for lip-sync).
   If credits run out: tell the owner; missing lines still render as bubbles/captions with estimated timing.
6. **Build scenes** in `src/episodes/epXX/index.tsx`, register the episode in `src/episodes/registry.ts`.
7. **Check stills**: `npm run stills -- epXX` (every 2 s + `contact.jpg`), `--every 1`, `--from 30 --to 60`, `--frames 100,200`.
   Fix overlaps, cut-off heads, unreadable bubbles, characters walking through props, empty frames.
8. **Render**: `npm run render -- epXX` → `out/epXX.mp4` (auto-mastered to −14 LUFS, −1.5 dBTP; voices are
   loudness-matched to −16 LUFS on import; music default volume 0.4 and ducks under speech). Send it to the owner.
9. **Update §5 continuity notes**, commit.
10. **On request**: 3 thumbnails (episode badge, big readable text, soft – not over-sharpened), title ideas,
    YouTube description with chapter timestamps (`chapters()` in `src/engine/episode.ts`, scene `title`s),
    9:16 Shorts in `src/shorts.ts` (render `npm run render -- epXX-short1`; includes "Full episode on YouTube" button).

## 4. Library cheat-sheet

```
src/engine/timeline.ts     say / narrate / sfx / music / wait / cue / beat  → automatic timing from audio lengths
src/engine/SceneContext    useScene(): frame, cue(), beat(), progress(), after(), at(), activeLine(), mouth()
src/engine/EpisodePlayer   scenes in sequence + voices + sfx + music (auto-ducks under speech, loops, fades)
src/stage/Stage.tsx        <Stage set cam vcam actors front overlay> – auto lip-sync, line moods, bubbles, captions
src/stage/camera.ts        camKeys (keyframed camera), shake, drift, walk (foot-locked), hop (squash & stretch)
src/rig/Character.tsx      the rig: moods, arm poses, walk/run, sitting, blink, breathing, held props
src/rig/looks.ts           Look options: hair, hat, neckwear, outfit, glasses, mustache, freckles, size, head, girth
src/sets/sets.tsx          Sky (day/sunset/night, drifting clouds, parallax), Hills, Ground, Room, Buildings, Grade
src/props/props.tsx        Tree Bush Flower Rock Fence StreetLamp Bench Table Chair Sofa WindowFrame Door PictureFrame Plant Box Sign Car Mug Phone Letter
src/fx/fx.tsx              ImpactStars DustPuff SweatDrop MotionLines Sparkles Emote Flash Vignette SpeedLines IrisWipe SoundWord TitleCard FullEpisodeButton
scripts/generate-audio.mjs SFX + music synthesis  (npm run sfx)
scripts/import-voices.mjs  voice download/convert/lip-sync data  (npm run voices:import -- epXX)
scripts/list-lines.mjs     dialogue list + cost estimate  (npm run lines -- epXX)
scripts/render-stills.mjs  check frames + contact sheet  (npm run stills -- <id>)
scripts/render-episode.mjs final MP4  (npm run render -- <id>)
```

- World coords: 1920×1080, ground line ≈ y 860–900. Actors' `x,y` = feet. Default adult ≈ 470 px tall.
- Moods: neutral happy angry sad surprised worried smug confused determined sleepy.
  Poses: down wave point hips shrug up think hold cross reach facepalm fist (or `[backArm, frontArm]`).
- SFX: pop boing whoosh swish thud bonk ding footstep click splat sparkle slideUp slideDown scratch crickets drumroll
  tada sadTrombone gulp honk knock creak phoneRing typing sting zap squeak rumble splash heartbeat gasp.
- Music: theme curious chase tender tension silly (all seamless loops).
- Composition props must be JSON – pass ids (`episodeId`), never components.
- Model sheet per character: `npm run stills -- RigSheet-<key>`.
- 9:16 framing: Stage uses `cam` zoomed ×1.5 by default; pass `vcam={{x, y, zoom}}` per shot to reframe.
- Bubbles place themselves above the speaker's head, move beside it if there's no room, never leave the safe area;
  a speaker who isn't on stage gets a name-tagged bubble at the top.

## 6. Environment notes

- In the cloud container Remotion can't download its own browser; `scripts/lib/browser.mjs` uses the pre-installed
  headless Chrome under `/opt/pw-browsers` when present (on the owner's computer Remotion downloads its own).
- Contact sheets need a system `ffmpeg` (the Remotion one has no `tile` filter); skipped gracefully if missing.
- ElevenLabs plan at setup: Starter, 80,017 credits/month (≈ 66k left on 2026-11-24). Test narrator line cost 73 credits.
